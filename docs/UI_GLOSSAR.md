# Begriffe in Anker

| Begriff | Bedeutung und Verwendung |
|---|---|
| Jetzt | Der nächste sinnvolle Schritt; keine Liste aller offenen Aufgaben. |
| Heute | Der Tagesplan mit Terminen, tatsächlichen Abschlüssen und eigenen Änderungen. |
| Heute anpassen | Tagesart, Unterstützung und weitere bewusste Änderungen am heutigen Plan. |
| Gedanke | Etwas Notiertes. Wird erst durch eine eigene Entscheidung zur Aufgabe. |
| Geparkt | Ein Gedanke mit einem selbst gewählten Zeitpunkt zum erneuten Ansehen. |
| Gesammelte Gedanken | Bewusst behaltene Gedanken ohne Verpflichtung oder erfundene Frist. |
| Aufgabe | Etwas Umsetzbares mit einem nächsten Schritt und gegebenenfalls Teilaufgaben. |
| Kleine Version | Eine ausdrücklich gewählte kleinere Handlung. Sie zählt, wenn sie tatsächlich gemacht wurde. |
| Wiedereinstieg | Der gemerkte konkrete nächste Schritt nach einer Unterbrechung. Kein neuer Aufgabentyp und kein Rückstand. |
| Erledigt | Tatsächlich gemacht. Ein Timerablauf, eine verstrichene Uhrzeit oder ein Download bestätigt keine Erledigung. |
| Heute nicht nötig | Bewusst für diesen Tag entfallen. Keine Erledigt-Haken oder zusätzlichen Punkte. |
| Pause | Ausdrücklich angehaltene Fokuszeit beziehungsweise selbst gestartete Arbeitspause. Beide bleiben getrennte tatsächliche Vorgänge. |
| Fokus-Puls | Eine selbst gewählte kurze Rückmeldung während des geöffneten Fokus. |
| Zeitübersicht | Technische, lokal abgeleitete Übersicht; im normalen Alltag ausgeblendet. |
| Gespeichert | Die lokale Speicherung wurde erfolgreich abgeschlossen. Keine Aussage über einen externen Empfang. |

Uhrzeiten erscheinen im 24-Stunden-Format, Daten deutsch. Der zentrale Helfer
`src/core/uiText.ts` behandelt Einzahl/Mehrzahl, Minuten und die Tageswörter des
tatsächlich betrachteten Plans. Pflichtangaben werden im jeweiligen Formular
erkennbar; ausführliche Hinweise und Datenschutztexte bleiben unter „Mehr
erfahren“ vollständig lesbar.
