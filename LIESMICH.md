# Anker – Code 14

Die App heißt auf dem Handy **Anker**. Version **1.4.0-rc.1 / Code 14**, Android ab Version 8.

1. ZIP vollständig herunterladen und entpacken.
2. **Anker-Code14.apk** antippen und die Installation bestätigen.
3. Falls Android fragt, deinem Browser bzw. Dateimanager das Installieren aus dieser Quelle erlauben.

Du hast einen Neustart der Testphase gewünscht und kannst die bisherigen beiden Apps vorher deinstallieren. Die neue APK verwendet weiterhin die Paketkennung `de.frnkrm.anker.mobile` und denselben Release-Schlüssel wie Anker Neu. Falls diese App noch installiert ist, ist auch ein direktes Update möglich.

Überarbeitet: drei Hauptbereiche Jetzt/Heute/Mehr, kompakter Jetzt-Bildschirm mit einer Hauptaktion, zusammengefasste Bereiche, gemeinsame Zeit-/Datums-/Dauerfelder, kompakte Routinezeilen mit Details, einheitliche Fokusansichten, Rückgängig beim Löschen, vereinfachte Formulare und verständlichere Begriffe. Freiwillige Funktionen bleiben freiwillig; keine automatischen Erledigt-Häkchen oder Strafen.

Automatisch bestanden: 912 Logiktests, 248 Browserfälle in GitHub-CI, 122 frisch ausgeführte Android-JUnit-Fälle. Zusätzlich PowerShell-/PC- und Updateprüfungen. Eine Installation auf einem echten Samsung mit diesem Build wurde hier nicht durchgeführt. Die sechs zusammengefassten Teststationen stehen unter Mehr → Einstellungen → Test- und Entwicklerwerkzeuge anzeigen → Gemeinsam testen.
